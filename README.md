**網頁弱點測試**：理解 SQL 注入登入繞過與指令注入（Command Injection）的基本原理，能在受控環境中執行基礎拼接符號測試。

- **環境建置與系統指令**：會使用 Linux 終端機基本指令，並操作過 OpenVPN 進行受控測試環境的連線。
